# PAGEFLOW · PDF 翻页动效工坊

把 PDF 变成一个可以导出成视频的 3D 翻页动画。上传 PDF → 在时间轴上打关键帧 → 一键渲染成 WebM。

全部在浏览器本地运行，**不上传任何文件、不依赖网络**：双击 `index.html` 即可使用（`file://` 直接打开也能跑）。

---

## 怎么用

1. 双击 `index.html`（推荐 Edge / Chrome；渲染需要 WebGL2，导出需要 WebCodecs，两个都缺时会自动降级而不是报错）。
2. 拖入自己的 PDF，或点 **示例** 载入内置的 14 页论文。
3. 左边点一个 **布局模式**（单页 / 堆叠 / 平铺 / 书本 / 扇形 / 环形 / 画廊 / 纵深）。
4. 在时间轴上拖动播放头到某个时刻，点 **+ 关键帧** 记下此刻的画面；
   再挪到下一个时刻，换布局 / 改 **聚焦页**（当前是哪一页当主角）/ 调 **镜头**（缩放、水平、垂直、旋转）/ 微调布局参数，然后再打一帧。
5. 按 **空格** 预览。相邻两帧之间会自动补间，所以「翻页」本身就是聚焦页在动、「切模式」是两种布局在互相变形。
6. 点右上角 **导出视频**，选画幅 / 分辨率 / 帧率，等进度条走完，**下载视频**。

时间轴上的方块可以直接拖动改时间；`总时长` 在左下角改。

## 快捷操作

| 操作 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← → | 逐帧后退 / 前进（按住 Shift 为 0.1s） |
| K | 在当前时刻加关键帧 |
| Delete | 删除选中的关键帧 |
| Home | 回到 0s |
| Esc | 关闭导出弹窗 |
| 点缩略图 | 把该页设为当前关键帧的聚焦页 |
| 拖关键帧 | 改它的时间 |

## 导出

- 画幅：16:9 / 9:16 / 1:1，舞台会实时跟着变。
- 分辨率：720p / 1080p / 1440p（按画幅的长边计算，短边自动换算，永远是偶数）。
- 帧率：24 / 30 / 60。
- 输出：**WebM（VP9）**，`PDF名-宽x高-帧率fps.webm`，可直接拖进剪映 / Premiere / Final Cut / 达芬奇。

导出是**逐帧离线渲染**，不是实时录屏：每帧都按时间轴精确取值再编码，所以掉帧不会影响画质，也不受窗口大小影响；导出期间界面卡顿是正常的，可以切到别的窗口等它跑完。

若浏览器不支持 WebCodecs，会自动退回 MediaRecorder 实时录制（画质与帧率稳定性略差，界面上会标明用的是哪条路径）。

## 技术说明

- 渲染：WebGL2 逐面片合成（`js/gl.js` + `js/engine.js`）。每页的四个角以**齐次坐标**交给 GPU（`gl_Position = vec4(2X/W-1, 1-2Y/H, 0, w)`），由光栅化器自己做透视除法与透视校正插值，所以斜到极致的页面上文字也不会错位、没有接缝；纹理恒开 mip 链 + 各向异性过滤，远景页面不会因为一步降采样而闪成条纹。
  - 没有 WebGL2 的环境自动退回 Canvas 2D 逐格仿射（把页面切成 4×4 小格分别贴图逼近透视），能用，但强透视下会有轻微接缝与摩尔纹。
  - 预览与导出走同一套合成器，成片和所见一致。
  - 合成用的 GL 画布不开 `preserveDrawingBuffer` 会周期性读到已被清空的缓冲（舞台闪白）；这里显式打开，并监听 `webglcontextlost`，显卡重置后自动重建合成器。
  - 排查用：`index.html?gl=0` 强制走 Canvas 2D 路径。如果闪烁只在默认路径出现、加 `?gl=0` 就好了，那就是显卡/合成器层面的事，把这个结论告诉我即可。
- 动画：关键帧之间**连聚焦页 focus 本身也一起缓动插值**，所以不管两个关键帧相差几页，中间每一张都会真的经过一遍，不会出现"跨度太大直接跳过去"。
  - 同布局：直接在这个连续的 focus 上采样布局，页面位移是连续的。
  - 书本：整本书是一条传送带，相邻页间距正好一个书脊，focus 每 +1 就翻一张；正在翻的那一张会抬起、绕书脊摆过去，翻过去的那张原地压住左页位、等下一张落下来才让位，所以翻页途中左半边不会空掉。翻到最后一页时整体宽度和位置平滑收回、单页居中。
  - 换布局：两端各采样一次再逐 pose 形变混合，端点值保持精确。
  - 叠放次序：同一布局内部用**整页**深度排序（纸片不该互相穿插，成型的扇形/画廊每页都是完整的）；只有跨布局形变的那一段才打开**逐像素深度测试**，两页真的互相穿过时按像素判遮挡，不会出现"后面那张一瞬间盖到最前面"的硬切。堆叠布局的 z 也改成随「到聚焦页的距离」单调下降，抽牌时不会再有卡片突然翻到最上层。
- 编码：`VideoEncoder`（VP9 / VP8 / AV1 依次尝试）→ 自写的极简 Matroska 封装器（`js/webm.js`）→ `Blob`。
- PDF：本地 vendor 的 pdf.js 3.4.120。为了兼容 `file://`，worker 脚本用普通 `<script>` 预加载，pdf.js 会自动走主线程 fake worker（控制台那句 `Setting up fake worker` 是正常的，不是错误）。代价是解析在主线程，所以首次载入会分页渲染并显示进度。
  - 页面缓存：≤48 页的文档整本常驻（更多页时按 LRU 保留 28 页），并且每帧都把「正在画面上」的页标记为最近使用，避免淘汰掉还要显示的页；真的未命中时用缩略图顶上而不是留空。载入后还会在后台把整本栅格化一遍，所以拖动时间轴、切布局时不会出现页面忽隐忽现或「先糊一下再变清晰」。

## 目录

```
index.html            页面骨架
styles/app.css        全部样式（深色剪辑器皮肤）
js/core.js            布局算法、缓动、关键帧采样
js/gl.js              WebGL2 合成器（齐次坐标贴图 / mip / 各向异性）
js/engine.js          3D 渲染管线（GPU 主路径 + Canvas2D 兜底）
js/pdfdoc.js          pdf.js 封装（分页缓存 / 缩略图 / 并发队列）
js/webm.js            WebM 封装器
js/export.js          视频导出（WebCodecs + MediaRecorder 回退）
js/ui.js              时间轴、检查器、拖拽、快捷键
js/app.js             状态机与主循环
vendor/pdfjs/         pdf.js 3.4.120（含 cmaps、standard_fonts）
assets/demo.pdf       示例 PDF
assets/demo.b64.js    示例 PDF 的 base64（为了让 file:// 也能一键载入）
tools/                开发期用的 Edge headless 截图 / 自动化测试脚本
```

`tools/` 只是开发辅助，删掉不影响使用。
